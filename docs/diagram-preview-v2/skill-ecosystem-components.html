Skill ecosystem review

Question. Which skills are established, overlapping, underdeveloped, redundant, or missing—and what kind of relationship connects them?

Where we are. The package has 48 current skills. The diagram keeps all of them visible, adds proposed composition infrastructure, and labels every reviewed handoff by relationship type.

Families and ownership
  • Intent skills own framing, interrogation, authority language, planning, and diagrams.
  • Long-horizon skills own strategic slicing, bounded execution, recovery, and continuation.
  • Repository, verification, writing, design, and data skills own narrower effects and artifacts.
  • The green composition layer is proposed infrastructure, not a current service inventory.
Composition boundaries

A solid path means a relationship is currently declared or supported. A dashed path means the relationship is proposed, indirect, overlapping, or still dependent on caller discipline. Repository contracts may describe effects, but they may never grant themselves authority.

Reading the shapes
Thick blue: established major skill. Thin gray: established minor or specialized skill. Orange: existing skill needing meaningful improvement. Green: missing or proposed component. Red: consolidation candidate; this is a review judgment. Yellow note: relationship type, present handoff, and missing contract.
Plain-language glossary
  • Callable contract: a machine-readable description of one bounded phase's inputs, outputs, effects, failures, and implementation binding.
  • Authority envelope: a ratified ceiling on what a composed harness may do.
  • Resolution lock: the exact accepted contracts, adapters, policies, and compiler identity for one build.
  • Claim: output that still requires controller observation or verification.
Evidence boundary

This is an architectural review artifact. It does not prove skill usage frequency, justify removal by telemetry, authenticate approval, implement callable contracts, or qualify any MetaBuilder harness. Red and orange classifications remain reasoned judgments.

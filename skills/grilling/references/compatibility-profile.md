# Explicit mediated-delegation compatibility profile

This optional profile changes transport when a host can create specialists only
through its orchestrator. It is never selected merely because direct
respondent delegation is unavailable. Native `spec`/`factory`/`debate`/`gradient`
retain their existing direct topology by default.

## Selection and capability binding

Prepare the concrete route, host capability evidence, scope and visibility
tradeoff before asking for an unresolved topology decision. Reuse explicit
selection of this same profile. If the host cannot route tasks and results as
required, record the missing capability and keep affected findings provisional;
do not invent a dispatcher or install capabilities.

In this profile the respondent still owns specialist questions, task context,
evidence standards, stop conditions, corrections/retries and synthesis. The
orchestrator transports those respondent-authored packets using actual host
calls and returns complete results to the respondent without research judgment,
answer rewriting or orchestration-owned synthesis. An invalid/out-of-scope
packet returns to the respondent for correction; transport does not widen
authority. Runtime failure is reported as failure, never a synthesized answer.

The mediated path is:

```text
respondent -> orchestrator transport -> specialist
specialist -> orchestrator transport -> respondent synthesis -> orchestrator
```

The orchestrator necessarily sees traffic the direct profile keeps within the
respondent subtree. Do not claim equivalent privacy, isolation or information
boundaries. Record the selected profile privately and describe the tradeoff in
plain language. A requested diagnostic must show this actual path rather than
reuse the direct-topology diagrams unchanged.

Role authority, evidence standards, bounded waves, synthesis-only phase,
minority preservation, question-only griller, user ratification and required
closing debate remain unchanged. This profile is not the `linear-runtime`
profile: the latter does not implement a specialist message transport.
